## 01. 웹 기초
**웹의 동작 개념**
- 서버에서 미리 준비해둔 것을 '받은 뒤', '그려주는 일'을 한다.
- 요청을 보내고, 받은 HTML 파일을 그려준다.
- 요청을 보내는 곳은 서버 api 이다.

## 03. HTML
**HTML 이란?**
- ```Hypertext Markup Language``` 의 줄임말으로, 브라우저 화면에 표시되는 문서를 작성하는데 쓰이는 Markup 언어이다.
- HTML은 ```tag``` 라고 불리는 요소드를 이용해 화면을 분할하고, 텍스트 이미지 하이퍼링크 등 배치한다.
- 각 태그들은 보통 시작태그 ```<태그명>``` 과 종료 태그 ```</태그명>``` 한쌍으로 이루어져있다.
- 각 HTML 태그에 ```style``` 속성을 부여하여 크기, 정렬, 글꼴, 색 등을 정해 꾸밀 수 있지만, CSS(Cascading Style Sheets)를 이용하면 한 곳에 모아서 볼 수 있고 여러 요소에 같은 속성을 부여할 수 있다.  

**HTML 기초**  
- HTML은 크게 head와 body로 구성되며, head안에는 페이지의 속성 정보가 있고 body안에는 페이지의 내용이 들어있다.
- head 의 요소: meta, script, link, title 등
- body 안에 들어가는 대표적인 요소들: div, p, img 등  

**HTML의 부모-자식 구조**
- HTML 요소는, "어떤 요소 안에 어떤 요소가 있느냐" 를 이해하는 것이 중요하다. 이를 tree 구조라고 한다.
- 상위에 하위요소를 감싸고 있는 요소를 부모(parent), 하위에 있는 요소를 자식(children) 이라고 한다.

## 04. CSS
**선택자(selector)**
- 선택자의 개념: class 값으로 태그를 선택(select)해서 꾸미기
    - 무엇을 꾸민다는 것은, 일단 선택해야 가능하다. 그래서 CSS에서는 class값으로 이름표를 달아준다.
    - 예를 들어 mytitle이라고 이름을 달아준 뒤, mytitle 이름표가 달린 부분들의 글씨를 빨간색으로 바꾸던지 하는 것이다.
    - 이름을 잘 지어야 한다.
    - CSS 사용하는 방법: <head> ~ </head> 안에 <style> ~ </style>로 공간을 만들어서 작성한다.
    - red-font라는 클래스를 가리킬 때, .red-font {...} 라고 써줘야 한다. .을 뺴먹지 말 것

**CSS 기초**
- CSS는 ```cascadeing style sheet```의 약자이다. HTML의 부모-자식 구조처럼 폭포가 위에서 아래로 흐르는 것 처럼, 위에서 부모가 디자인 적용 시 자동으로 자식도 디자인이 적용된다.

```
/* 모든 태그에 적용하고 싶을 때 */
* {
    속성: 선택지;
}

/* 특정 태그를 지칭할 때 */
태그 {
    속성1: 선택지1;
    속성2: 선택지2;
}

/* 클래스 이름 앞에는 .을 찍는다. */
.클래스 {
    속성: 선택지;
}

/* 아이디 앞에는 #을 붙인다. */
#아이디 {
    속성: 선택지;
}

/* 특정 클래스를 갖는 특정 태그를 지칭할 때는 클래스를 뒤에 붙여 쓴다 */
태그.클래스 {
    속성: 선택지;
}

/* 자식 선택자는 > 뒤에 적는다 */
/* 즉, 아래는 '아이디'라는 아이디를 갖는 요소 바로 안의 '태그' 태그를 선택한 것이다 */
#아이디 > 태그 {
    속성: 선택지;
}

/* 자손 선택자는 띄어쓰기로 구분한다. */
/* 즉, 아래는 '클래스'라는 클래스를 갖는 '태그1' 태그 안에 있는 모든 '태그2'를 선택한 것이다 */
태그1.클래스 태그2 {
    속성: 선택지;
}
```   

**CSS 파일 분리**
- ```<style> ~ </style> 부분이 너무 길어지면 보기 어려울 수 있는데, 이럴 땐 .css 파일을 따로 분리할 수 있다.
- 분리한 파일을 HTML에서 참조할 수 있기 때문에, 같은 스타일의 여러 페이지에 적용하고 싶을 때 유용하다.

## 05. 부트스트랩
**부트스트랩이란**
- 트위터에서 개발한 무료 프론트엔드 프레임워크, 쉽고 빠른 반응형 웹디자인을 만들 수 있다.
- 부트스트랩을 사용하면, HTML 요소에 특정 클래스를 적어주기만 하면 CSS를 직접 작성하지 않아도 원하는 스타일을 바로 적용할 수 있다.
- 다양한 스타일이 정의된 CSS파일이 인터넷에 저장돼 있고, 그거를 가져다가 쓰는 방식이다.
